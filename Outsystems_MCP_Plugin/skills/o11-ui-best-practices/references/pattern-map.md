# Design element to OutSystems UI pattern

| Design element | Prefer |
|---|---|
| Content card/tile | Card, Card Item, Card Sectioned |
| Row with avatar/title/meta | List Item Content, User Avatar |
| Multi-step flow | Wizard |
| Section switcher | Tabs |
| Collapsible details/FAQ | Accordion |
| Inline message | Alert |
| Transient confirmation | Notification |
| No data / first run | Blank Slate |
| Side navigation | Sidebar, Submenu |
| Mobile secondary actions | Action Sheet, Bottom Sheet |
| Status chip | Tag, Badge |
| Dense editable table | OutSystems Data Grid |
| Browse + edit | Master Detail |
| Paging | Pagination |
| Date input | Date Picker, Date Picker Range |

Steps: list screens and data needs, put design tokens in the theme first, build Blocks once, include interaction states (hover, focus, disabled, error), and ask before accepting custom CSS or JavaScript where no pattern fits.
